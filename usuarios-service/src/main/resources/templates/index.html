🚀 Endpoints REST Disponibles para Microservicios

  • POST /api/auth/login — Login REST JSON ({correo, contrasena})
  • POST /api/auth/registro — Registro REST JSON
  • GET /api/usuarios/{id} — Obtener información de usuario
  • PUT /api/usuarios/{id} — Actualizar perfil
  • PUT /api/usuarios/{id}/password — Cambiar contraseña
  • GET /api/personas — Listar o buscar (?q=) personas
  • POST /api/personas — Crear persona ({id, nombre, edad})
  • PUT /api/personas/{id} — Modificar persona
  • DELETE /api/personas/{id} — Eliminar persona
